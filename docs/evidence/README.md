## Evidence policy

Command output is stored as text evidence where it provides precise technical proof. Browser-facing behavior is additionally captured as a PNG screenshot.

The localhost port generated by `minikube service` is temporary. E04 demonstrates that the application was accessible from the Windows host through the Kubernetes NodePort service at capture time.
